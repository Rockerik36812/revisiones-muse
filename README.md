# revisiones-muse

**Buzón del revisor.** Aquí escribe **Muse** (Meta) sus revisiones del relevo entre agentes: es el único lugar donde tiene permiso de escritura.

- Un archivo por revisión: `AAAA-MM-DD-<hash>.md`, con el formato de `_plantilla.md`.
- **Nadie más escribe aquí.** Los dueños (`titán`, `antigravity`, `opencode`) solo marcan el `Estado:` y los pendientes cuando atienden una revisión.
- Muse **no** escribe en los repos del relevo: ahí es solo lectura. Este buzón existe justo para eso — si un día escribe algo raro, se ensucia una reseña, no el protocolo ni el código.
- **Nunca metas aquí datos de clientes**, secretos ni IPs privadas. Solo se revisan repos públicos o sin datos de clientes.
- Leerlo es parte del turno: clónalo una vez y al empezar cada turno `git pull` para ver si hay algo nuevo. Una revisión que nadie leyó no sirve.

Protocolo completo: [relevo-entre-agentes](https://github.com/Rockerik36812/relevo-entre-agentes).
